# Arhilab Смета 0.7.0 — release notes

**Android:** `ru.arhilab.estimate`, `versionName 0.7.0`, `versionCode 11`; Android 8.0+ (`minSdk 26`). Это первая серверная основа 0.7.0 при сохранении автономного режима приложения.

## Возможности

- Несколько независимых смет на объект, наценка на работы, неизменность исторических цен.
- Платежи, расходы, ход работ, журнал и задачи на сегодня, закупки.
- КП, подробная и краткая смета; утверждение сохраняет неизменяемый снимок, Android формирует многостраничный PDF.
- Backend: организации, сотрудники, роли, устройства и отзыв сессий; REST API `/api/v1`, ревизии, идемпотентные операции, конфликты, файловые и документные метаданные.
- Offline-first: объекты и основные операции продолжают работать в зашифрованной локальной базе без сети.

## Обновление с 0.6.2

Установите подписанный **Release** APK поверх существующего Release без удаления приложения. Сначала создайте и проверьте отдельную зашифрованную резервную копию. CI проверил `adb install -r`, миграцию схемы, сохранение администратора, объектов, смет, строк, материалов, этапов, платежей и локальной сессии. Package и сертификат Release не изменены. Debug APK предназначен для установок с постоянным Debug-сертификатом; он не обновляет Release.

## Ограничения

Backend не развёрнут как публичный сервис. Производственная Android-интеграция с новым API, первоначальный перенос локальных данных на сервер и автоматическая синхронизация между устройствами пока не включены. Существующий локальный режим и ручной механизм общей базы сохраняются. PDF не загружается на сервер автоматически; обмен происходит через системный Share Sheet. Расход и упаковки некоторых SKU требуют проверки. Старую Debug 0.6.1 с утраченным одноразовым ключом нельзя обновить поверх установки.

Ключи и пароли в репозитории и релизных файлах отсутствуют.
