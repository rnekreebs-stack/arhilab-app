# Arhilab Смета 0.8.0-alpha6 — клиентский PDF

Экспорт открывается из выбранной сметы или вкладки «Документы» → «Создать PDF». Пользователь выбирает техническую смету или коммерческое предложение, видимость количества/цен/итогов, режим «Только итоги разделов», фотографию обложки и раздела, сроки, примечания, реквизиты и подписи. Перед созданием обязательный постраничный предпросмотр PDF. После подтверждения PDF получает номер и новую версию в документах выбранной сметы; старые версии не перезаписываются. «Открыть» и «Поделиться / Сохранить» используют системный Android viewer/share sheet.

Локальный `PremiumPdf` строит широкие векторные страницы 960×540 пунктов через Android `PdfDocument`: титул (для КП), разделы с таблицами и продолжениями, сводку, при наличии данных страницу условий. Строки переносятся по измеренной ширине текста. Исходные денежные суммы берутся только из клиентского снимка F7. `F7Documents.row` сохраняет `importedAmount` как итог строки и не умножает его на `qty`. В клиентский PDF не попадают закупка, себестоимость, цена рабочего, маржа или внутренняя наценка. Итог учитывает сохранённую клиентскую наценку, доставка и скидка приходят из сметы.

PDF создаётся полностью без сети и хранится в приватных файлах приложения; в базе остаются тип, дата, проект, смета, имя, размер, номер, версия и неизменяемый клиентский снимок. Защищённый backup сохраняет снимок/метаданные и фото объекта, **но не включает двоичный файл сгенерированного PDF**. После восстановления файл можно открыть заново: приложение регенерирует PDF из сохранённого снимка; отсутствующее фото пропускается. Для хранения самостоятельной копии используйте «Поделиться / Сохранить». Система Android предоставляет встроенный шрифт sans-serif с кириллицей; отдельные платные шрифты и сервисы не используются.

Проверка в CI: 5/50/200 строк, 15 разделов, режим только итогов, переносы, кириллица, ₽/м², итог OCR-строки 5 000 000 ₽ при количестве 12, версии документов, upgrade alpha5 → alpha6 и существующие сценарии импорта/архива/backup. Образцы PDF и screenshots предпросмотра приложены к Android run.
