# Изменения Arhilab Смета

## 0.7.0 — 2026-10-05

- F1: несколько смет, наценка на работы и сохранение сумм старых смет.
- F2–F6: платежи, расходы, ход работ, задачи и «Сегодня», закупки.
- F7: версионированные клиентские КП и сметы, снимок цен, локальный PDF и экспорт через Android Share Sheet.
- Backend: PostgreSQL migrations 001–018, авторизация и роли, устройства, API синхронизации и конфликтов, файлы и документы.
- CI: Android Debug/Release с постоянными сертификатами, тесты обновления, offline и emulator smoke; backend миграции, integration, Docker и health.
- Обновление Release 0.6.2 → 0.7.0 проверено без очистки данных. Package `ru.arhilab.estimate` и сертификат Release сохранены.

Производственный Android-адаптер нового сервера, автоматический перенос старой локальной базы и развёртывание сервера не входят в выпуск. См. [release notes](RELEASE_0.7.0.md).

## 0.6.2

Стабильная локальная основа с постоянными сертификатами, зашифрованным backup/restore, миграциями и offline. Подробности: [история версии](arhilab/RELEASE_0.6.2.md).
# 0.8.0-alpha1 — preview, ветка arhilab-0.8.0-ui-local

- Новый визуальный слой WebView: дизайн-токены, контрастные карточки, типографика, нижняя навигация, быстрые действия.
- Переработаны «Сегодня», список и карточка объектов; улучшена навигация к смете, материалам, задачам, документам и фото. Добавлены фильтр и сортировка объектов, локальный поиск.
- `versionCode 12`; package, сертификаты подписи, схема локальных данных и бизнес-расчёты не изменены. Production backend не развёртывался.

# 0.8.0-alpha2 — preview, ветка arhilab-0.8.0-ui-local

- Сметы: фильтр «Активные / Архив», действия «В архив», «Восстановить», «Удалить»; архив доступен для просмотра.
- Удаление сохраняет tombstone, строки и связанную историю в зашифрованной базе. Требуется точное название и усиленное предупреждение при зависимостях.
- Локальная схема 10 автоматически делает старые сметы активными; перед миграцией создаётся зашифрованный снимок, backup/restore сохраняет состояние.
- `versionName 0.8.0-alpha2`, `versionCode 13`, package и постоянные сертификаты подписи прежние. Production backend не подключался.
