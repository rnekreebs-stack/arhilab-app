# Arhilab SM 0.3.0 — 24.09.2026

Обновление ставится поверх 0.2.0 и 0.1.0: пакет `ru.arhilab.estimate`, ключ подписи и локальные учётные записи сохранены. `versionCode` = 3. Удаление приложения удаляет локальную базу и фото, поэтому для рабочего телефона сначала сделайте резервную копию.

## Фото и скорость
Снимки шифруются отдельными файлами AES-GCM в приватном каталоге приложения. В базе остаются идентификатор и дата. При первом запуске 0.3.0 прежние фото из базы 0.2.0 и 0.1.0 переносятся автоматически. Для интерфейса фото загружаются только при открытии соответствующей вкладки либо при подготовке КП/PDF. Сметы и расчёты не изменены.

## Защищённые копии
Администратор задаёт отдельный пароль длиной от 12 символов. Экспорт `.arhilab` шифруется AES-256-GCM; ключ получается PBKDF2-HMAC-SHA256, 210 000 итераций, отдельная случайная соль. Внутри копии находятся объекты, сметы, платежи и фото. Пароли учётных записей туда не входят. Старые незашифрованные `.json` копии можно выбрать при восстановлении, для чего экран всё равно предлагает поле пароля. Существующие учётные записи на устройстве остаются прежними.

Не теряйте пароль новой копии. Для первой проверки восстановления возьмите тестовую копию и тестовый объект: восстановление заменяет список объектов на телефоне.
