# Arhilab SM 0.4.0 — 24.09.2026

Установите APK поверх предыдущей версии: package id `ru.arhilab.estimate` и ключ подписи сохранены, `versionCode` = 4. Локальная база, учётные записи и фото сохраняются при обновлении. Перед обновлением рабочего телефона рекомендуется сделать защищённую резервную копию.

## Наценка на материалы

В каждом объекте откройте «Материалы» и выберите ставку 8%, 10% или 12%. По умолчанию действует 8%, в том числе для объектов прежних версий. При изменении ставки приложение сохраняет её в объекте и пересчитывает цену уже добавленных материалов и включённых комплектов по их сохранённой закупочной стоимости. Новые материалы получают текущую ставку. Обновляются суммы сметы, плановая прибыль, остаток к оплате и КП/PDF. Суммы ранее записанных платежей остаются фактическими и не меняются.

Наценка действует на материалы и комплекты. Цена работ, стоимость закупки, доставка и скидка остаются такими, как заданы в смете. Если в импортированной старой записи нет закупочной стоимости, её цену автоматически пересчитать нельзя: она остаётся прежней.
