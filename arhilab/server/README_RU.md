# Сервер синхронизации Arhilab

Node.js 20+; сторонних npm зависимостей нет. Сервер хранит только зашифрованную копию объектов и хеш пароля администратора. Пароли локальных пользователей и ключи AndroidKeyStore на сервер не отправляются.

Первый запуск: `ARHILAB_ADMIN_LOGIN=admin ARHILAB_ADMIN_PASSWORD='длинный-секретный-пароль' ARHILAB_DATA_DIR=/var/lib/arhilab node server.mjs`. После создания учётной записи можно убрать пароль из переменной окружения. Каталог данных хранить на постоянном диске, делать его резервные копии. Для смены пароля нужен отдельный регламент: не удаляйте `account.json` при уже существующем `vault.json`, иначе копия станет недоступной со старым паролем.

Сервер слушает `127.0.0.1:8787`. Опубликовать его через обратный прокси с действительным сертификатом HTTPS. В Android вводить только URL вида `https://your-domain.example`; HTTP приложение отвергает. Установить резервное копирование каталога данных и ограничить доступ к нему. При потере пароля зашифрованную копию восстановить нельзя.

На первом телефоне: войти локальным администратором, открыть «Настройки → Общий доступ», указать адрес сервера и пароль, нажать «Подключить» и «Отправить». На новом телефоне: выбрать «Войти в общую базу», указать те же адрес, логин и пароль; приложение создаст локальную учётную запись администратора для работы офлайн. Для обмена последующими изменениями используются кнопки «Отправить» и «Получить». Сервер отклоняет отправку устаревшей версии; изменения другого устройства не затираются без подтверждения.

До подключения сервера приложение остаётся автономным. Историю версий сервер не ведёт. Для одновременного редактирования на нескольких телефонах необходимо согласовать порядок синхронизации: получить последнюю версию перед работой, отправить после завершения. При конфликте сохраните защищённую локальную копию до решения, какую версию считать основной.
