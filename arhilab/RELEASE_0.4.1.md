# Arhilab SM 0.4.1 — исправление открытия базы

Исправлена ошибка `Caller-provided IV not permitted`, которая возникала при переносе фотографий из базы прежних версий в отдельные зашифрованные файлы. Для ключа AndroidKeyStore IV при шифровании теперь создаёт сам Android; при чтении используется сохранённый IV. Формат зашифрованных фото и базы не меняется.

Существующая база не удаляется при установке обновления поверх 0.4.0. После неудачной попытки переноса исходная база должна оставаться на телефоне: код сохраняет её только после успешной записи фото. Не удаляйте приложение и не очищайте его данные. При запуске 0.4.1 перенос повторится.

Подпись и идентификатор приложения сохранены, `versionCode` = 5. Функции выбора наценки 8%, 10% и 12% из 0.4.0 остаются.

Проверка: тест с криптопровайдером, отклоняющим переданный приложением IV при шифровании, проходит; также проверены шифрование и чтение фото. Физический Android-телефон для этой сборки недоступен, поэтому запуск с конкретной базой пользователя ещё не подтверждён.
