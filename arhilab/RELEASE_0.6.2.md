# Arhilab Смета 0.6.2 — состояние выпуска

Версия 0.6.2 (code 9), package `ru.arhilab.estimate`. Локальная схема 2, резервная копия зашифрованного файла до миграции и откат при ошибке. Полный экспорт формата `Arhilab-2` хранит хеши и соли пользователей внутри отдельно зашифрованного файла; сеансы и пароли в открытом виде не экспортируются. Импорт проверяет формат и схему, показывает подтверждение и сохраняет текущую базу перед заменой. Предыдущие копии `Arhilab-1` остаются читаемыми. Добавлены read-only проверка целостности, экран «О приложении», журнал ошибок, технический экспорт, базовые дизайн-токены и локальный экран «Сегодня».

**Подпись:** исходный постоянный Release keystore найден в приватном архиве; alias `arhilab`, сертификат SHA-256 `21:BD:A2:21:8D:2B:3C:9F:FE:CE:23:79:EE:03:C7:79:22:7C:66:D7:29:F5:E8:7A:FF:FD:E0:58:87:C7:54:10`. Release можно собирать только с этим ключом и GitHub Secrets, сохранив совместимость с ранними Release APK на том же сертификате. 0.6.1 Debug из CI #20 подписан другим временным ключом; технически невозможно установить 0.6.2 поверх этого распространённого APK без его закрытого ключа. Наличие одинакового package и versionCode 9 недостаточно. Запланированный CI upgrade-test использует 0.6.1 из исходников с тем же постоянным Debug ключом и проверяет миграцию, но не снимает указанное ограничение реальной установки.

Ограничения: перед первой установкой постоянный Debug ключ нужно сохранить в GitHub Secret. PIN и биометрия пока только интерфейс расширения. Удалённый отзыв сессий и серверная синхронизация не реализованы. Каталог не содержит проверенного расхода и упаковок на каждый SKU. Фотодокументы доступны, файлы PDF не добавлены. Старые копии `Arhilab-1` содержат объекты, но не хеши пользователей; новые полные копии защищены отдельным паролем.
