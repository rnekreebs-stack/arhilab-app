# Arhilab Смета 0.6.1

Обновление исходного Android-приложения 0.6.0: имя, versionCode 8, защищённая сессия, заменяемые позиции комплекта, закупочный лист, целые упаковки и запас, ввод фактических закупок и фотографий чеков, согласование допработ, прогресс этапов и график платежей, сводка объекта, экран «Сегодня», документы и информация о версии прайса. Локальный JSON прайс обновляется с резервированием предыдущего файла. Автоснимок базы шифруется тем же ключом устройства; экспорт в отдельный файл остаётся защищён отдельным паролем.

Ограничения данных: исходные комплекты не задают расход каждой позиции и упаковку; пользователь должен ввести проверенные значения для точной закупки. Фактическая прибыль доступна только после подтверждения фактических затрат для всех позиций. Чеки добавляются как фотографии; вложение PDF остаётся на следующую версию. Принудительное серверное прекращение сессии при полностью автономной работе требует будущего механизма синхронизации. Предварительная классификация 261 работы — `MANUAL_KITS_261.md`.

Результаты CI и Android smoke-test заполняются после реального запуска GitHub Actions.
