# F7: клиентские документы

Ветка `arhilab-0.7.0-architecture`, техническая версия Android `0.7.0` (`versionCode` 11). F7 добавляет к выбранной смете КП, подробную и краткую смету. Рабочая ветка не является релизом 0.7.0 и не меняет `main`.

## Локальное поведение

- Только администратор создаёт документ и утверждает черновик. Каждый документ принадлежит конкретному объекту и смете.
- При создании сохраняется снимок клиентских полей, цен и итогов. Изменение сметы создаёт следующую версию, утверждённая версия не пересчитывается.
- Режим материалов: детализация, только сумма или скрыть. Отдельно можно скрыть цену за единицу материала и включить разделы. Итоговая цена сохраняется в каждом режиме.
- PDF строится Android `PdfDocument` исключительно из сохранённого снимка. Внешним приложениям передаётся временный `content://` URI через неэкспортируемый provider и разрешение на чтение.
- Структура данных обновляется с версии 8 на 9 с резервной копией перед миграцией. Существующие объекты, сметы, закупки и локальная сессия не заменяются.

## Сервер

Миграция `018_f7_client_documents.cjs` добавляет клиентские документы с организационной изоляцией, версиями, номерами и ключами идемпотентности. Авторизованный администратор использует `/api/v1/client-documents`; данные для нового серверного снимка берутся из сохранённых строк сметы, а не из текущего каталога. Операции F1 передают метаданные через существующую очередь и изменения доступны второму устройству. Неадминистративные роли не получают документы в F1 pull и снимках.

Локальный PDF не загружается на сервер автоматически: для обмена используется Android Share Sheet. Бинарный серверный обмен потребует отдельного этапа с явным согласием и политикой хранения. Два независимых офлайн устройства могут выбрать одинаковый номер; сервер отклонит конфликт и сохранит локальные данные до разрешения.

## Проверки

`backend`: `npm ci`, `npm run lint`, `npm run typecheck`, `npm run migrate:test`, `npm run test:unit`, `npm run test:integration`, `npm run build`.

`Android`: `.github/workflows/build.yml` компилирует источники, собирает Debug/Release с постоянными ключами, проверяет подпись и выполняет 0.6.2→F7 и F6→F7 upgrade, offline smoke и cold restart. Результаты инструментальных тестов и APK сохраняются в Artifacts.
