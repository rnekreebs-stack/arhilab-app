# Arhilab Смета 0.6.2

Исходники актуального Android-приложения находятся в `arhilab/` (Java Activity + WebView). Package `ru.arhilab.estimate`, versionCode 9, minSdk 26, targetSdk/compileSdk 35. Каталог: 254 SKU, 371 работа, 110 автоматических комплектов, 261 работа с ручным подбором.

Локальная база и маркер сеанса зашифрованы Android Keystore. При обновлении приложения без очистки данных старые сметы читаются без изменения сумм. При обычном повторном запуске вход восстанавливается на этом устройстве; ручной выход отзывает локальный сеанс. Общий сервер сохраняет прежний режим ручной синхронизации и требует настройки. Все основные операции доступны без интернета.

Расход каждого SKU не задан в исходных автоматических комплектах. Закупочный лист показывает их состав, а размер упаковки и расход необходимо подтвердить перед расчётом упаковок. Замена одного SKU пересчитывает комплект по явно заданному расходу; отмена замены возвращает исходную цену. Отчёт по неполным связкам: `arhilab/MANUAL_KITS_261.md`.

Сборка: `bash arhilab/build.sh debug` при JDK 17 и Android SDK 35 и постоянном Debug keystore. GitHub Actions → **Arhilab Смета 0.6.2 Android** запускает Java/Node/Playwright тесты, Android upgrade/offline smoke и публикует APK и отчёты. Требуется GitHub Secret `ARHILAB_DEBUG_KEYSTORE_BASE64`, постоянный Debug keystore с alias `androiddebugkey` и паролем `android` (или изменить workflow и параметры на значения своего ключа). Release создаётся только при Secrets `ARHILAB_KEYSTORE_BASE64`, `ARHILAB_KEYSTORE_PASSWORD`, `ARHILAB_KEY_ALIAS`, при необходимости `ARHILAB_KEY_PASSWORD`; проверяется исходный сертификат Arhilab. Закрытые ключи никогда не коммитятся.

**Ограничение обновления ранее выданного APK:** Debug 0.6.1 из Actions #20 подписан одноразовым закрытым ключом, который не сохранился. Его сертификат SHA-256 `9B:31:10:26:9D:84:06:D4:27:57:70:10:04:FA:15:BB:CB:00:53:CF:40:FF:09:4D:97:41:68:EB:FC:33:EC:C5`. Новый постоянный Debug ключ не сможет подписать обновление поверх этого APK; Android отклонит установку с `INSTALL_FAILED_UPDATE_INCOMPATIBLE`. CI проверяет обновление с 0.6.1, пересобранной из того же commit с постоянным ключом. Для реальных данных на одноразово подписанной 0.6.1 сначала экспортируйте доступную резервную копию объектов; затем удалите прежнюю установку, установите 0.6.2, создайте администратора и восстановите объекты. Копия 0.6.1 не сохраняет учётные записи. Никогда не удаляйте приложение до проверки экспортированного файла и пароля.

Ранний каталог `app/` и Gradle в корне относятся к прежней заготовке и не участвуют в сборке.
