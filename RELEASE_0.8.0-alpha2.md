# Arhilab Смета 0.8.0-alpha2

Preview в ветке `arhilab-0.8.0-ui-local`; стабильный `main` остаётся 0.7.0.

## Сметы

- В карточке сметы меню ⋮ позволяет перенести её в архив или удалить; в архиве доступно восстановление.
- Архив скрывает смету из активного списка и активной суммы. Её строки и связанная история сохраняются.
- Удаление требует отдельного подтверждения и ввода точного названия. При связанных платежах, этапах, документах, закупках и других данных показывается усиленное предупреждение с предложением архива. Удалённая запись остаётся локально как tombstone для сохранения истории. В интерфейсе она не отображается; восстановление tombstone пока не предусмотрено.
- На старте миграция схемы 9 → 10 присваивает старым сметам статус `active`. Шифрованный снимок до миграции и существующий backup/restore сохраняются.

## Совместимость

Package `ru.arhilab.estimate`, `versionName 0.8.0-alpha2`, `versionCode 13`. Debug обновляет Debug с тем же сертификатом; Release обновляет Release. Перед установкой создайте проверенную зашифрованную копию.

Production backend не развёрнут. Маркеры жизненного цикла остаются в локальной базе и backup; распространение tombstone между устройствами требует отдельного расширения sync API и не заявляется в этом preview.
