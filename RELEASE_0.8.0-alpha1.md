# Arhilab Смета 0.8.0-alpha1

Предварительная версия для проверки интерфейса. Стабильной остаётся 0.7.0 в `main`.

## Изменения

- Более спокойная визуальная система: navy, графит, нейтральный фон, единые карточки, элементы форм и состояния.
- «Сегодня» показывает активные объекты, просроченные и ближайшие этапы, ожидаемый платёж для администратора, локальные изменения и состояние подключения.
- Нижняя навигация: Сегодня, Объекты, добавить, Документы/Задачи, Ещё. Быстрые действия открывают существующие формы.
- Список объектов получил поиск по названию и адресу, фильтр статуса и сортировку. Карточка объекта показывает готовность и основные показатели с учётом роли.
- Локальный поиск по объектам, работам и материалам; улучшены галерея фотографий и переходы между разделами.

## Данные и обновление

Package `ru.arhilab.estimate`, `versionName 0.8.0-alpha1`, `versionCode 12`. Формат локальных записей и расчёт смет не менялись. Для обновления поверх 0.7.0 используйте APK того же типа и с тем же постоянным сертификатом подписи; заранее создайте и проверьте зашифрованную копию в настройках. Debug и Release не устанавливаются поверх друг друга.

Приложение продолжает работать без сети; существующий backend остаётся кодовой основой, production-инфраструктура не подключена. Вручную настроенная ранее серверная связь остаётся опциональной.

Эта ветка не предназначена для публикации как стабильный 0.8.0. После CI и оценки экранов потребуется отдельное решение о релизе.
